## 额度差 25 倍，落到实际产出是什么概念

这是两档最硬的差别。Pro 每月 1000 额度，Ultra 每月 25000 额度，25 倍的差距。

额度怎么消耗？每次生成按模型、时长和分辨率扣费，官方没有公布固定价目表，而且明确说明模型成本变化快，最新扣费标准要在产品内选模型时查看。有一条参考量级：有第三方测评估算过，一条带原生音频的 Veo 3 标准时长片段大约消耗 50 额度。按这个算法，Pro 的月额度对应 20 条上下，Ultra 则是数百条的空间。

换个更具体的场景。一条 60 秒的短片通常要拆成 8 到 12 个片段生成，算上重试和废片，额度开销大概在 500 上下。也就是说，Pro 一个月的额度差不多够做一两条这种短片，Ultra 就宽裕得多，可以放开手试错。

另外视频比图像费额度得多。同样的额度拿去生成图片能撑很久，拿去跑 Veo 视频很快见底。评估自己需要哪档时，先想清楚你生成的主要是哪类内容。

两个补充：Pro 支持额度加油包，用完可以临时补购，官方帮助文档也确认了这一点；而按第三方资料的说明，月度额度当月没用完就清零、不滚存，所以“囤额度”这个思路不成立。

## 画质上限：1080p 和 4K 的分界线

免费版自带 2K 图像放大，Pro 提到 1080p，Ultra 是 4K 图像和视频放大。

这条差别的意义取决于你的成片去向。只发社交媒体的话，1080p 基本够用；如果素材要进剪辑软件二次加工、投大屏播放，或者交付方对分辨率有硬性要求，4K 就是绕不开的门槛。做商用交付的团队，基本只能落在 Ultra。

## 到底选哪一档？

按使用强度分三种情况：

- **只是好奇**：免费版先跑起来，功能清单和付费版重合度很高，够你判断自己会不会持续用。
- **每周稳定产出**：Pro 是主流选择。1000 额度加 1080p，额度用完还有加油包兜底，首月 $0 的促销把试错成本压到了零。个人创作者、自由职业者、做内容排期的运营，基本都在这一档。
- **高频量产或商用交付**：需要 4K、月额度消耗远超 1000，或者本来就要 YouTube Premium 和大存储，Ultra 才开始划算。前三个月 $124.99/月是入场窗口。

判断标准可以很机械：把上个月的生成量乘以单条消耗，估算出月额度需求，超过 1000 再考虑 Ultra。只凭“我要认真做视频”就上 Ultra，大概率是额度用不完、钱先花出去了。
